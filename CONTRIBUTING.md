# Contributing

Bug reports are welcome through GitHub Issues. Please use the bug-report form,
remove sensitive investigation data, and never include API keys, credentials,
private targets, or raw provider responses.

This is a personal project and external pull requests or code contributions are
not accepted. Unsolicited external pull requests will be closed. The repository
owner uses personal branches and pull requests so that CI validates changes
before they are merged.

Security vulnerabilities must be reported privately as described in
[SECURITY.md](SECURITY.md), not through a public Issue.
