# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Do not open a public Issue for a suspected vulnerability. Use the repository's
**Security** tab and select **Report a vulnerability** to submit a private
vulnerability report to the maintainer.

Do not include real investigation targets, Shodan API keys, credentials, raw
provider responses, or other sensitive research data unless the maintainer
explicitly requests a sanitized reproducer in the private report.
